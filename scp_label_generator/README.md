# SCPMod 收容室标牌生成器

这是一个完全离线的 Python 3 + Pillow 标牌生成工具。它为 Minecraft Fabric 模组 **SCPMod** 批量输出可直接作为物品/方块贴图使用的 PNG；默认尺寸为 **512×512**，支持任意自定义尺寸、可选照片和四种差异明显但统一为基金会工业档案气质的主题。

## 交付内容

- `gen_labels.py`：主生成器，不依赖网络素材或第三方包（仅需 Pillow）。
- `labels.example.json`：16 条样例数据，即 4 个 SCP × A/B/C/D 四种主题。
- `examples/`：一次批量运行生成的 16 张 512×512 PNG。

## 快速运行

在本文件夹内执行：

```powershell
# Windows（按题目给定的 Python 路径）
& '<Python 路径>' .\gen_labels.py .\labels.example.json .\examples

# 已将 Python 加入 PATH 时
python gen_labels.py labels.example.json examples
```

只渲染某一个主题时，使用 `--theme` 覆盖 JSON 中每条记录的主题：

```powershell
python gen_labels.py labels.example.json .\out-A --theme A
```

自定义尺寸：

```powershell
# 正方形
python gen_labels.py labels.example.json .\out-768 --size 768

# 非正方形（适合某些 Minecraft 资源布局）
python gen_labels.py labels.example.json .\out-wide --width 640 --height 512
```

`--seed` 默认为 `173`。相同输入和种子会得到稳定的纹理、磨痕和噪点；需要另一套自然磨损分布时可以换种子。

## JSON 数据格式

最小记录：

```json
[
  {
    "number": "SCP-173",
    "class": "EUCLID",
    "note": "有意识且暴力",
    "photo": null,
    "theme": "A"
  }
]
```

支持字段：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `number` | 字符串 | `SCP-XXX` | SCP 编号；会进入文件名和大号主标题 |
| `class` | 字符串 | `EUCLID` | 项目等级；会映射等级色条。支持 `SAFE`、`EUCLID`、`KETER`、`THAUMIEL`、`NEUTRALIZED`、`APOLLYON`、`ESOTERIC` 等，未知等级使用中性灰蓝 |
| `note` | 字符串 | `行为特征待确认` | 一句风险/行为备注，中文会按字符自动折行并自动缩字号，避免压字/越界 |
| `photo` | 字符串或 `null` | `null` | 相对于 labels.json 的本地图片路径，也可填绝对路径；找不到或为 null 时使用有纹理的“图像受限”占位 |
| `theme` | `A`/`B`/`C`/`D` | `A` | 当前记录的主题；命令行 `--theme` 可统一覆盖 |
| `warning_cn` | 字符串 | `未经授权禁止进入` | 底部门外中文警示语 |
| `warning_en` | 字符串 | `UNAUTHORIZED ENTRY PROHIBITED` | 底部门外英文警示语 |
| `site` | 字符串 | `SITE-19` | B 主题档案表头 |
| `record` | 字符串 | `CONTAINMENT RECORD` | B 主题档案类别 |
| `timestamp` | 字符串 | `SITE-19 // 03:17:42` | C 主题终端时间戳 |

也接受 `{ "labels": [ ... ] }` 形式的 JSON 外壳，便于将来加入全局配置。

## 四种主题与 512×512 排版草图

设计坐标均以左上角为 `(0,0)`，右下角为 `(512,512)`。脚本先以 3 倍超采样绘制，再缩放到目标尺寸，线条和中文在 Minecraft 贴图中更清楚。

### A｜工业警示风

- 配色：旧纸灰米底 `#CFC9B5`，警示黄 `#EEBE23`，近黑 `#191A18`，等级色条使用 `class` 对应颜色。
- `0–92`：黄黑顶部识别带、基金会标识、ACCESS 编号。
- `108–220`：占宽的编号卡片，编号是最大文字层级。
- `236–292`：等级卡片；`307–390`：行为备注；`307–445`：右侧照片/受限图像框。
- `402–459`：黄色警示三角与风险提示；`461–484`：斜向黑黄警示条；`484–512`：中英门禁警示。
- 纸纤维、噪点、边角磨痕和内边框使其像使用过的工业收容门牌，而不是平面色块。

### B｜基金会公文风

- 配色：米白档案纸 `#E2D8BC`，基金会红 `#912B2B`，深墨色 `#2E2C27`，等级色条保留项目等级辨识度。
- `13–92`：双重红色档案边框与品牌栏。
- `108–152`：SITE / RECORD / STATUS 三格档案表头。
- `174–267`：大号编号和档案标签；`278–308`：项目等级色签。
- `326–423`：左侧观察记录表格，右侧固定照片框；印章位于编号右上方，不遮挡编号。
- `442–492`：签批分隔线、双语警示与 FOUNDATION PROPERTY 页脚。
- 纸张纹理、纤维线、双线表格和半透明“已收容”印章提供档案感。

### C｜终端监控风

- 配色：深绿黑终端底 `#121C1B`，基金会荧光绿 `#6DEE97`，时间戳琥珀 `#F1B840`，项目等级使用独立状态灯。
- `22–87`：监控网格、品牌、时间戳；`105–203`：最大号异常编号与 FEED 标题。
- `111–177`：右侧状态卡片；`224–359`：左侧行为日志、右侧受限图像框。
- `383–430`：CONTAINMENT / LOCKED / REMOTE OVERRIDE 数据行。
- `92–474`：细扫描线叠加；线宽和低对比度经过控制，不压过正文；`454–488`：终端式双语门禁条。

### D｜金属铭牌风

- 配色：拉丝钢灰 `#939793`，深钢 `#373C3A`，黑色压痕 `#222523`，等级色条使用项目等级色。
- `8–38`：多层金属边缘；四角螺钉和竖直等级色条。
- `36–91`：深钢顶栏、压印式品牌识别；`120–216`：高光偏移 + 深色压痕的雕刻编号。
- `235–273`：等级条；`300–414`：左侧风险铭文，右侧带四个压角的照片/受限图像框。
- `438–459`：黑黄警示斜条；`459–488`：金属铭牌双语警示。
- 横向拉丝、细噪点、螺钉高光、内阴影和雕刻字模拟实体金属牌，不使用需要下载的材质。

## 字体与中文降级策略

按优先级查找本机字体：

1. Windows：`C:\Windows\Fonts\msyhbd.ttc`、`msyh.ttc`、`simhei.ttf` 等。
2. Linux 常见目录中的 Noto Sans CJK / 思源黑体。
3. Pillow 内置字体作为最后兜底，脚本会在终端打印警告。

为了保证中文不变成方块，建议在 Windows 机器上保留微软雅黑或黑体；本机题目给定的 `msyhbd.ttc` 会优先用于粗体层级。字体加载和主题配置都集中在脚本顶部，后续可直接添加企业字体或新等级。

## 设计与验收要点

- 每张图都有：SCP 编号、项目等级、风险/行为备注、照片或质感化占位、基金会标识与“控制 · 收容 · 保护”、中文和英文门禁警示。
- 编号 > 等级 > 备注，且编号、等级、备注、照片均处于相互独立的版面区域。
- 照片区包含深色相框、内衬、边界线和四个压角；无照片时不是刺眼纯灰块，而是带取景框、斜纹和“图像受限”的受限档案位。
- 主题 A/B/C/D 的网格、材质、色彩和信息结构明显不同，但均保留基金会品牌、双语警示和可批量套用的字段体系。
- 输出文件名形如 `SCP-173_A.png`；同编号同主题重复记录时自动追加 `_2` 等后缀，不覆盖旧结果。

## 生成结果快速检查

```powershell
python -c "from PIL import Image; from pathlib import Path; p=Path('examples'); print(len(list(p.glob('*.png'))), sorted({Image.open(f).size for f in p.glob('*.png')}))"
```

期望结果为 `16 [(512, 512)]`。如使用 `--size 768`，则尺寸集合应为 `[(768, 768)]`。
