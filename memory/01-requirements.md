## 1. 项目定位
SCP 题材 Minecraft Java 模组，Fabric 加载器，锁定 **MC 26.2**。无主线剧情。沙盒自由玩法。核心承载是**随机生成的大型收容站点（Jigsaw 拼装）** + 设施内的**收容单元/操作终端**方块 + **收容失效事件链**。

## 3. 非目标（**待用户确认**，推荐清单见 O1）
推荐明确排除在 v1 之外：
- 剧情 / 任务 / NPC 对话系统
- 自定义维度（如 SCP-106 口袋空间）
- 合成 / 经济 / 成长系统
- 图形化配置界面（Coth Config 等）
- 多版本兼容（26.2 之外）
- SCP 图鉴 / 成就 / 收集度 UI
